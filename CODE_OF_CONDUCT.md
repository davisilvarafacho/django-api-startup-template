# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)
versão 2.1 como seu código de conduta.

Em resumo: seja respeitoso e colaborativo. Não são toleradas assédio,
discriminação ou linguagem ofensiva.

Condutas inadequadas podem ser reportadas para **davi@rafacho.dev**.
Todas as reclamações serão analisadas e investigadas de forma justa.
