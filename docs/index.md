# DRF Base API

Uma base opinativa para APIs Django REST Framework, com infraestrutura local em
PostgreSQL e Redis, tarefas assíncronas, cache, documentação OpenAPI e controles
de qualidade.

Use o menu conforme sua necessidade: o **Tutorial** ensina o primeiro fluxo; **Como
fazer** reúne procedimentos; **Referência** documenta contratos e padrões; e
**Explicações** registra decisões e contexto arquitetural.
