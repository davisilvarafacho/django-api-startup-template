# Convenções

Use Conventional Commits e mantenha a versão do pacote igual à versão do OpenAPI.
O changelog segue Keep a Changelog.

Ao escrever código, prefira resultados intermediários nomeados quando eles tornam o
fluxo mais claro, por exemplo `resultado = buscar(); transformar(resultado)`, em
vez de aninhar chamadas. As convenções completas para código assistido são mantidas
no repositório em `.ai/CONVENTIONS.md`.
