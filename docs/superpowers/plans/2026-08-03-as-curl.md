# as_curl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Converter uma `requests.Response` em um comando `curl` copiável e, opcionalmente, salvá-lo como arquivo `.curl` na raiz do repositório.

**Architecture:** Um módulo isolado em `utils/curl.py` obtém a requisição preparada em `response.request`, serializa seus argumentos com `shlex.quote` e devolve o comando. Quando solicitado, cria o arquivo por UUID e registra seu caminho com o logger padrão.

**Tech Stack:** Python 3.12, requests, pytest, Ruff.

## Global Constraints

- A interface pública é `as_curl(response, *, save_to_file=False) -> str`.
- Todos os headers, inclusive credenciais, são reproduzidos literalmente.
- O comando inclui método, URL preparada, headers e corpo, se existir.
- Argumentos são seguros para shell POSIX.
- `save_to_file=True` cria `<uuid4>.curl` na raiz, registra o caminho em `INFO` e propaga erros de I/O.
- Não adicionar dependências nem recursos de filtragem, execução ou formatação.

```python
import shlex


def as_curl(response, *, save_to_file=False):
    request = response.request
    command = ["curl", "-X", request.method]
    for name, value in request.headers.items():
        command.extend(["-H", f"{name}: {value}"])
    if request.body:
        body = request.body.decode() if isinstance(request.body, bytes) else request.body
        command.extend(["--data-raw", body])
    command.append(request.url)
    return " ".join(shlex.quote(str(part)) for part in command)
```
